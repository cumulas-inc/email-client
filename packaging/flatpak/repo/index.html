Cumulas Mail

Email, calendar, contacts and tasks for Microsoft 365, Outlook.com and IMAP accounts.

Install Cumulas Mail

Opens in your software center, such as GNOME Software or KDE Discover, which also keeps the app up to date. It needs Flatpak, which most Linux distributions include.

From a terminal

flatpak remote-add --if-not-exists cumulas https://flatpak.cumulas.co/cumulas.flatpakrepo
flatpak install cumulas co.cumulas.Mail

Then flatpak update keeps it up to date.

The runtime comes from Flathub

Cumulas Mail runs on the GNOME runtime, which Flatpak installs from Flathub. Most distributions set Flathub up with Flatpak; if yours didn't, add it first: 

flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo

Signed by Cumulas

Every build is signed with the Cumulas key, which Flatpak checks before it installs or updates anything from this repository: cumulas-flatpak.gpg, fingerprint @FINGERPRINT@.
