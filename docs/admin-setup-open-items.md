# Organization setup: what the first real run must show

Organization setup (**Set up or check for your organization**,
`crates/core/src/orgsetup/`) and the Cumulas Signatures relay were built and tested against
modeled organizations only. These open items, R1 to R18, are what no test here can show. The code
names them where it depends on them (for example "R8" in `orgsetup/apply.rs`). Before a release,
run setup in a real tenant (see **Before release** in the [README](../README.md)), keep **Copy
setup details** and **Copy details for IT**, and record next to each item what was seen.
